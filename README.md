# Digit Recognition using Artificial Neural Networks (ANN)

This project implements a handwritten digit recognition system using an Artificial Neural Network (ANN) built with TensorFlow and Keras. The model is trained on the MNIST dataset, which consists of 70,000 grayscale images of handwritten digits (0–9). The project demonstrates the complete deep learning workflow, including data preprocessing, model architecture design, training, evaluation, and prediction. It serves as a practical introduction to neural networks and image classification, highlighting how ANNs can learn meaningful patterns from pixel data to accurately classify handwritten digits. The project was developed using Python, TensorFlow, Keras, NumPy, Matplotlib, and Jupyter Notebook.
